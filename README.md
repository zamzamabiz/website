# website

The official website for ZamZam Biz, integrated with the [ERP-CRM system](https://github.com/zamzamabiz/erp-crm).

## ERP-CRM Integration

This website connects with the [zamzamabiz/erp-crm](https://github.com/zamzamabiz/erp-crm) repository to provide:

- Customer relationship management (CRM) features
- Enterprise resource planning (ERP) data
- Unified business operations through a single web interface
